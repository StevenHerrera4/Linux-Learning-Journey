# Installing Fastfetch on Pop!_OS

**Objective:**
Install fastfetch to display system information directly in the linux terminal.

**Operating System:**
Pop!_OS

## Step 1 — Update
Update the package Repositories

```bash
# sudo apt update
```

## Step 2 — Install
Installation of fastfetch

```bash
# sudo apt install fastfetch
```
**note:** If the package is unavailable, check your Pop!_OS version and available repositories


## Step 3 — Check fastfetch version

```bash
# fastfetch --version
```

## Step 4 — Run fastfetch

```bash
# fastfetch
```

## Result
Fastfetch displays information about the operating system, kernel, RAM, CPU, GPU, uptime, and other systems details.
