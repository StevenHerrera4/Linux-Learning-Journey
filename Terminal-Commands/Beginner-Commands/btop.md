
# Installing and Using btop on Pop!_OS

**Objective:** Install and use btop to monitor CPU, RAM, system processes, and other hardware resources IN REAL TIME.

**Operating System:** Pop!_OS (Ubuntu-based)

## Step 1 — Update Package Repositories

```bash
sudo apt update
```

## Step 2 — Install btop

```bash
sudo apt install btop
```

## Step 3 — Check btop Version

```bash
btop --version
```

## Step 4 — Run btop

```bash
btop
```


## Step 5 — Exit btop

Press `q` to close btop and return to the terminal.

## Result

btop provides a real-time terminal interface for monitoring CPU usage, memory consumption, system processes, and other available system statistics.
